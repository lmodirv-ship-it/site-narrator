# خطة: لقطات احترافية لواجهة Hn-MAKER

## الهدف
إنتاج 8–10 صور تسويقية احترافية بمقاس **1920×1080**، كل صورة عبارة عن لقطة من واجهة البرنامج موضوعة داخل إطار نافذة macOS (أزرار traffic light + ظل ناعم + خلفية تدرّج ملوّن mesh gradient)، جاهزة للموقع/المتجر/الـREADME.

## مصدر اللقطات
سيتم تصفّح المعاينة الحيّة للتطبيق على viewport 1920×1080 والتقاط الحالات التالية (سأعدّل القائمة حسب ما هو موجود فعلاً بعد فحص الواجهة):

1. الصفحة الرئيسية / Landing (Hero)
2. لوحة المدخلات (URL + اسم الموقع + اللغات)
3. بطاقة فحص الخادم المحلي (LocalServerSetupCard)
4. لوحة المسجّل (RecorderStudio) في وضع الخمول
5. لوحة المسجّل أثناء التشغيل (Overlay/Progress)
6. لوحة المسجّل بعد الانتهاء (نتائج + روابط ملفات MP4/SRT)
7. مشغّل العرض (TutorialPlayer)
8. شاشة سجلات FFmpeg / SSE الحيّة
9. صفحة "مشاريعي" (my-projects) إن وُجدت
10. لقطة عامة بعرض كامل تجمع أهم العناصر

> إن كانت بعض الحالات تتطلّب بيانات وهمية لإظهارها (مثل "أثناء التشغيل")، سأستخدم mock state مؤقت في الواجهة فقط للقطة ثم أُزيله — دون مساس بالمنطق.

## التنفيذ
1. تشغيل preview على 1920×1080.
2. التنقّل بين المسارات والتقاط screenshot لكل حالة (حفظ مؤقت في `/tmp`).
3. تشغيل سكربت `skill/product-shot` على كل لقطة مع preset مناسب:
   - الصفحات الداكنة → `midnight` أو `ocean`
   - شاشات التشغيل → `aurora`
   - الصفحات الفاتحة → `sunset` أو `peach`
   - لقطة واحدة بكل preset للتنويع
4. حفظ المخرجات النهائية في `/mnt/documents/product-shots/` بأسماء واضحة:
   ```
   01-hero.png
   02-recorder-input.png
   03-server-check.png
   ...
   ```
5. عرضها كـ `<presentation-artifact>` للتحميل المباشر.

## التحقق
- فحص كل PNG بصرياً للتأكد من: عدم اقتصاص نصوص، توازن الإطار، نقاء التدرّج، حدة الصورة.
- في حال وجود مشكلة في لقطة معينة (مثل overlay لم يظهر)، إعادة الالتقاط مع تعديل الـ state.

## المخرجات
- 8–10 ملفات PNG بدقة عالية في `/mnt/documents/product-shots/` جاهزة للتحميل.
- لا تغييرات دائمة في الكود (أي mock state يُزال بعد الالتقاط).
