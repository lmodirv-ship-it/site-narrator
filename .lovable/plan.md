# HN Website Tutorial Video Maker — الخطة

## ملاحظة مهمة حول البيئة
طلبت العمل داخل `C:\tools` على ويندوز، لكن مشاريع Lovable تعمل في بيئة سحابية (Linux/Cloudflare Workers) وليس على جهازك المحلي. سأبني المشروع هنا، ويمكنك بعد ذلك تحميله أو نسخه إلى `C:\tools` عبر GitHub أو زر التحميل.

كذلك بعض الأدوات المطلوبة (Playwright/Puppeteer/FFmpeg لتسجيل شاشة فعلي بالمتصفح) **لا تعمل** داخل بيئة التشغيل السحابية للـ Workers (لا child_process، لا متصفح حقيقي، لا FFmpeg ثقيل). لذا سأقترح بنية واقعية تعطيك MVP فعلياً يشتغل.

---

## البنية المقترحة (MVP حقيقي قابل للتشغيل)

### الواجهة (HTML/CSS/JS داخل React + Tailwind)
نموذج يستقبل:
- رابط الموقع
- اسم الموقع
- اللغة (عربي/إنجليزي/…)
- نوع الصوت (قائمة أصوات ElevenLabs)
- مستوى الشرح: سريع / متوسط / كامل

### خط الإنتاج الخلفي (Server Functions داخل TanStack Start)

1. **تحليل الموقع** — Firecrawl (`scrape` + `map`) لجلب صفحات الموقع، النصوص، الروابط، ولقطة شاشة لكل صفحة.
2. **توليد سكريبت الشرح** — Lovable AI Gateway (Gemini) يأخذ محتوى الصفحات ويولّد سكريبت مقسّم لمشاهد (scene = صفحة + نص + هدف نقرة).
3. **توليد الصوت البشري** — ElevenLabs TTS لكل مشهد (MP3).
4. **بناء الفيديو** — Remotion في السكربوكس:
   - كل مشهد = لقطة شاشة الصفحة كخلفية
   - مؤشر فأرة SVG يتحرك بـ `interpolate()` نحو منطقة الزر/القسم المستهدف
   - الصوت يُركّب على المشهد بنفس مدته
   - يخرج MP4 نهائي إلى `/mnt/documents/` للتنزيل

### تدفق الاستخدام
المستخدم يملأ النموذج → زر "أنشئ الفيديو" → شريط تقدم يعرض المراحل (تحليل/سكريبت/صوت/رندر) → رابط تحميل MP4.

## ما يحتاج تفعيلك
- **Lovable Cloud** لتخزين المشاريع والفيديوهات الناتجة
- **Firecrawl connector** (لتحليل المواقع)
- **ElevenLabs connector** (للصوت)
- **Lovable AI** (متوفر تلقائياً)

---

## الحدود الواقعية للـ MVP
- لقطات الصفحات ستكون **صوراً ثابتة** عالية الجودة (من Firecrawl screenshot)، وليس تسجيل فيديو حي للمتصفح. شكلياً يبدو كـ screen recording لأن المؤشر يتحرك فوق الصورة والصوت يشرحها.
- الحد الأقصى لمدة الرندر في السكربوكس: ~10 دقائق، أي ~30 ثانية لكل صفحة و~5-8 صفحات في كل مرة.
- اللغات المدعومة في الصوت: كل اللغات المدعومة من ElevenLabs (عربي مدعوم بصوت طبيعي).

---

## الوقت المتوقع للبناء
- إعداد المشروع + الواجهة: ~5 دقائق
- تكامل Firecrawl + AI للسكريبت: ~5 دقائق
- تكامل ElevenLabs + Remotion للرندر: ~10 دقائق
- اختبار end-to-end: ~5 دقائق

**الإجمالي: ~25 دقيقة بناء فعلي.** كل فيديو ينتج خلال 2-5 دقائق حسب عدد الصفحات.

---

## أسئلة قبل البدء
1. هل تريدني أن أشغّل Lovable Cloud + Firecrawl + ElevenLabs الآن وأبدأ البناء؟
2. هل تكفي **8 صفحات كحد أقصى** لكل فيديو في الـ MVP؟
3. هل توافق على أن المشاهد ستكون **صور صفحات + مؤشر متحرك + صوت** (وليس تسجيل متصفح حي)؟

بعد موافقتك أبدأ التنفيذ مباشرة.
